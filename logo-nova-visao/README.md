# Nova Visão · a mesma logo, para cada aplicação

A logo é a **Original refinada**: o logo atual redesenhado com as medidas tiradas da imagem original (lentes, aro, haste, onda, cantos), com as letras pesadas e compactas. Nada do desenho muda. Muda só o formato, a cor de fundo e o tamanho, conforme o uso.

- `sistema.html` / `sistema.png`: todos os formatos e quando usar cada um.
- `aplicacoes.html` / `aplicacoes.png`: a logo aplicada (fachada, sacolas, cartão, rede social, site, celular, estojo, etiqueta e receituário).
- **`kit-logo-nova-visao/`**: os arquivos finais de cada adaptação (SVG, PDF e PNG transparente), com guia de uso (`LEIA-ME.md`) e o conjunto de favicon, ícone de app e avatar. `nova-visao_kit-logo.zip` é o mesmo kit compactado.
- `sistema/*.svg`: fontes vetoriais usadas para gerar o kit e as pranchas.
- `tools/`: geradores (`python3 tools/sistema.py` e depois `node tools/kit.js`). Fontes (OFL, Google Fonts): Outfit e Fredoka. `referencia-atual.jpg` é a imagem enviada.

Formatos: horizontal (cor, fundo escuro, sobre laranja ou foto, uma cor café), com assinatura ÓTICA (embaixo e em linha), vertical, símbolo (e versão de traço reforçado para tamanhos pequenos), só o nome, avatar circular, ícone de app, favicon e selos (laranja, em contorno e café, com borda ondulada).
